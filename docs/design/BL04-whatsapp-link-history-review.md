# WhatsApp — histórico de vínculo: hipótese não adotada

Reconciliado em **28/10/2026**. **Registro histórico, sem implementação a executar a partir
deste documento.**

A tabela de períodos de vínculo continua sendo uma hipótese não aprovada, sem
migration/grants. Os leitores antigos descritos no estudo foram alterados: materiais já
atribuídos continuam no mesmo negócio após troca, e a entrega simulada escolhe o número
ativo novo. Não exigir tabela de histórico nem espera do cliente como pré-requisito dessa
jornada.
